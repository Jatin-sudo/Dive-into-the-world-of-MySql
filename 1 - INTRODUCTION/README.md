# 01. Introduction

## 📊 SQL

Welcome to the first SQL chapter! 🤩

SQL (short for **Structured Query Language**) is a programming language designed to **manage and retrieve data stored in databases**.

It’s a staple in both **Data Science** and **Web Development**.

> 💡 Fun fact: SQL was developed at IBM in the 70s and was originally called **SEQUEL (Structured English Query Language)**.  
> You can pronounce it as **“S-Q-L”** or **“sequel.”**

---

## 🧠 What are SQL Queries?

SQL statements, or **queries**, are instructions that the database understands.

They allow us to:
- Retrieve information
- Filter data
- Sort or group results
- Modify data
- And much more
